# Instrucciones para Claude (Claude Code / Claude Desktop)

Esta carpeta es mi **segundo cerebro**: notas Markdown estilo Obsidian sobre mi vida, mi negocio y mis áreas personales.

- Lee siempre `PERFIL.md` primero: es quién soy.
- Antes de responder sobre mí, busca en las notas (`grep`) y cita las que uses con `[[Título]]`.
- Cuando te cuente algo nuevo y duradero, guárdalo: amplía la nota que ya exista o crea una nueva en
  `10-Vida/`, `20-Negocio/` o `30-Areas/<Área>/`. Una idea por nota, enlaces `[[...]]` y `#etiquetas`.
- `00-Bandeja/` es material sin procesar: clasifícalo cuando te lo pida.
- Si aprendes algo importante de mí, actualiza `PERFIL.md` (breve).
- Nunca borres información valiosa ni inventes datos.
